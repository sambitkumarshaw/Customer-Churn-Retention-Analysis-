# 📊 Customer Churn & Retention Analytics (Power BI & Python)

## Project Overview

This Customer Churn and Retention Analysis project was developed using **Python** and **Microsoft Power BI** to analyze customer behavior, track churn trends, and identify at-risk accounts. The dashboard and exploratory data analysis help business and retention teams monitor revenue exposure, customer lifecycle segments, and engagement metrics for proactive decision-making.

---

## Tools Used

* **Python** (Pandas, NumPy, Data Cleaning & RFM Modeling)
* **Microsoft Power BI**
* **Power Query**
* **DAX**

---

### 🎛️ Interactive Filters

---

## Key Insights

* Analyzed **93K customers** generating **$15.42M in revenue** using Python to track overall churn and retention patterns.
* Applied **RFM (Recency, Frequency, Monetary) analysis** to identify **75K churned users**, resulting in a high-level **80.1% churn rate** across the analyzed dataset.
* Built interactive Power BI dashboards using **DAX measures** to track core performance metrics.
* Highlighted **38K at-risk customers** representing **$4.97M in revenue exposure**, enabling targeted re-engagement campaigns.
* Identified specific behavioral drop-off points that can guide marketing and customer success teams in improving retention strategies.
